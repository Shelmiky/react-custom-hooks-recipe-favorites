# Избранные рецепты

Учебный React-проект по теме кастомных хуков.

## Реализовано

- В карточке рецепта есть визуальная звёздочка избранного.
- Кнопка добавляет рецепт в избранное и удаляет его оттуда.
- Состояние избранного вынесено в кастомный хук `useFavorites`.
- `RecipeList` принимает callback `onToggleFavorite` и передаёт его каждой `RecipeCard`.
- Добавлен переключатель всех рецептов и избранного.
- Форма добавления рецепта показывает ошибки для пустых названия, описания и категории и блокирует отправку до исправления.
- При изменении поля его ошибка исчезает; валидация покрыта тестами.
